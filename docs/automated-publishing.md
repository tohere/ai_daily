# Hacker News AI 自动发布与 Cloudflare Pages 部署

本项目通过 GitHub Actions 每天自动执行以下流程：

1. 从 Hacker News 热门列表中筛选未发布且明确与 AI 相关的外部文章。
2. 调用星期天AI（Weekly Day AI）兼容 OpenAI 的接口，生成中英文双语文章。
3. 将文章写入 `src/data/generated-posts/`。
4. 运行内容测试和 Astro 构建，确认产物可用。
5. 自动提交生成的 JSON 到仓库。
6. 将生成文章提交到 GitHub，由 Cloudflare Pages GitHub 集成自动构建和部署。

## 工作流

- `.github/workflows/daily-publishing.yml`：默认每天北京时间 08:15（UTC 00:15）运行，也可以在 GitHub Actions 页面手动执行；默认每次生成 2 篇文章。

## GitHub Secrets

在仓库的 **Settings → Environments → ai_daily_env** 中配置：

| 名称 | 说明 |
| --- | --- |
| `WEEKLY_DAY_AI_API_KEY` | **Environment secret**，星期天AI API Key。 |

不要把 API Key 写入代码、文章 JSON、日志或 Git 提交。仓库已经通过 `.gitignore` 忽略 `.env`。

## GitHub Variables（可选）

在 `ai_daily_env` 的 **Environment variables** 中可以配置或覆盖默认值；`WEEKLY_DAY_AI_BASE_URL` 和 `WEEKLY_DAY_AI_MODEL` 也应放在这里：

| 名称 | 默认值 |
| --- | --- |
| `WEEKLY_DAY_AI_BASE_URL` | 例如 `https://www.weekly-day.top/v1` |
| `WEEKLY_DAY_AI_MODEL` | 例如 `gpt-5.6-luna` |
| `DAILY_ARTICLE_COUNT` | `2` |
| `HN_FETCH_LIMIT` | `50` |
| `HN_MIN_SCORE` | `50` |
| `HN_AI_KEYWORDS` | 内置 AI 关键词列表 |
| `HN_MIN_COMMENTS` | `10` |
| `WEEKLY_DAY_AI_TEMPERATURE` | `0.4` |
| `WEEKLY_DAY_AI_MAX_TOKENS` | `5000` |
| `WEEKLY_DAY_AI_REQUEST_TIMEOUT_MS` | `90000` |
| `WEEKLY_DAY_AI_REQUEST_RETRIES` | `2` |
| `HN_FETCH_CONCURRENCY` | `8` |
| `HN_REQUEST_TIMEOUT_MS` | `12000` |
| `HN_REQUEST_RETRIES` | `3` |

## Cloudflare Pages 准备工作

1. 在 Cloudflare Pages 中通过 GitHub 集成连接仓库。
2. 构建命令使用 `pnpm build`，输出目录使用 `dist`。
3. 在 Cloudflare Pages 项目中绑定 `https://www.weekly-day.top` 对应的自定义域名。

Cloudflare Pages 负责 GitHub 提交后的构建和部署；GitHub Actions 只负责生成文章、测试、构建并提交 JSON 文件。

## 本地验证

在项目根目录运行：

```powershell
pnpm test:content
pnpm content:ai:dry-run
pnpm build
```

真实发布命令需要完整环境变量：

```powershell
pnpm content:ai:publish
```

该命令会访问 Hacker News、调用 AI 接口，并写入正式文章目录，请不要在没有配置好 API Key 的情况下执行。

## 文章披露与来源

每篇自动生成文章都会由程序固定添加以下披露文案，并将品牌链接到 [https://www.weekly-day.top/](https://www.weekly-day.top/)：

- 中文：本文使用星期天AI中转站大模型，基于 Hacker News 内容自动生成。
- English: This article was automatically generated by the Weekly Day AI gateway model using content from Hacker News.

文章详情页还会提供原文链接和 Hacker News 讨论链接。

## 失败处理与重试

- Hacker News 请求和 AI 请求均带有超时与有限次数的重试。
- 单篇原文抓取失败时，仍会使用 Hacker News 元数据生成文章，并在提示词中降低断言强度。
- 只有内容测试和 Astro 构建成功后，工作流才会提交生成文章。
- 工作流使用并发锁，避免同一时间运行多个每日发布任务。
- 如果 AI 或 Cloudflare Secrets 未配置，手动运行会明确失败，不会生成可提交的半成品。

## 持续集成

`.github/workflows/ci.yml` 会在针对 `master` 的 Pull Request 中运行内容测试和 Astro 构建，避免未通过验证的修改进入发布分支。
